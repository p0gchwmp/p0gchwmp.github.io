Personal AI Harness

Personal AI Harness is a private AI assistant used by its owner to securely search, read, summarize, and organize information from the owner's own Gmail and Google Calendar. It is a non-commercial personal software-development project and is not offered as a public consumer service.

What the app does

  • Searches the owner's Gmail for messages relevant to an owner-requested task.
  • Reads selected Gmail messages so the owner can review or summarize them.
  • Searches the owner's Google Calendar for events and schedule information.
  • Reads selected calendar events for owner-requested planning and review.

Google data access

The private Google-read component requests only read-only Gmail and Google Calendar permissions. It does not send email, delete or archive mail, modify labels, create or edit calendar events, delete events, or respond to invitations.

OAuth credentials stay local to the owner's computer and are not published to this website or a public repository.

Project access

This application is intended for private personal use by its owner. Access to Google account data occurs only after the account holder completes Google's OAuth consent flow.
