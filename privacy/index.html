Privacy Policy

Effective date: August 24, 2026

Personal AI Harness is a private, owner-operated AI assistant. This Privacy Policy explains how the application accesses, uses, stores, and protects Google user data. The application is intended for personal use by its owner and is not offered as a public consumer service.

1. Google data the app accesses

The private Google-read component requests only read-only Gmail and Google Calendar permissions.

  • Gmail read-only — search for and read the owner's Gmail messages when requested.
  • Google Calendar read-only — search for and read the owner's calendar events when requested.

The local read component does not request permission to send email, delete or archive messages, modify labels, create or edit calendar events, delete events, or respond to calendar invitations.

2. How Google user data is used

Google user data is used only for owner-requested personal-assistant features, including finding relevant emails or events, displaying selected details, summarizing or organizing information, and helping the owner plan based on their own account information.

Google user data is not used for advertising, marketing profiles, credit decisions, surveillance, or sale to third parties.

3. Storage and processing

  • OAuth client credentials and refresh tokens are stored locally on the owner's Windows computer.
  • OAuth tokens are not exposed as conversational-model output and are not published to a public repository.
  • Google account data is treated as private account data and is processed locally by default.
  • The application does not intentionally persist complete Gmail message bodies or Calendar event contents to public services.
  • User-requested local artifacts or summaries may be stored locally when the owner explicitly requests that result.

4. Sharing and disclosure

Personal AI Harness does not sell Google user data and does not share Google user data with advertisers or data brokers. Raw Google account data is not sent to external services by the private Google-read component unless the owner explicitly requests a separate action that requires such disclosure.

5. Google API Services User Data Policy

Personal AI Harness's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

6. Security

The application uses OAuth 2.0 rather than storing the owner's Google password. Access and refresh tokens are kept in the owner's local harness environment. The private Google-read capability is intentionally limited to read-only Gmail and Calendar scopes.

7. Revoking access

The owner can revoke the application's Google Account access at any time from Google Account security settings. Revoking access prevents further authenticated Google API requests until authorization is granted again.

8. Data retention and deletion

Local OAuth credentials can be deleted from the owner's computer at any time. Temporary data produced during an owner-requested read operation is retained only as needed to complete that operation, except when the owner explicitly chooses to save a local artifact, summary, or record.

9. Children's privacy

Personal AI Harness is not directed to children and is intended solely for the private use of its owner.

10. Changes to this policy

This policy will be updated if the application materially changes how it accesses, uses, stores, or shares Google user data.
